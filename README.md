# Ροπή και ισορροπία · Κλειδωμένη έκδοση τάξης

Η [σελίδα μαθημάτων](https://ntsomnii-1856.github.io/ropi/) ανοίγει με κωδικό που δίνει ο/η εκπαιδευτικός.

Αυτό το αποθετήριο περιέχει μόνο τη σελίδα εισόδου και κρυπτογραφημένα μαθήματα. Ο κωδικός και το μη κρυπτογραφημένο εκπαιδευτικό περιεχόμενο δεν αποθηκεύονται εδώ. Δεν υπάρχουν στοιχεία μαθητών.

Η αποκρυπτογράφηση γίνεται στη συσκευή, με Web Crypto, PBKDF2/SHA-256 (600.000 επαναλήψεις), τυχαίο salt και AES-256-GCM. Ο κωδικός δεν αποστέλλεται σε εξυπηρετητή ούτε αποθηκεύεται από την εφαρμογή. Απαιτείται ξανά μετά από επαναφόρτωση ή κλείδωμα.

Η ύλη είναι η Μηχανική στερεού σώματος, Μέρος Α΄ της Φυσικής Γ΄ Λυκείου: 14 βασικά μαθήματα, 7 εφαρμογές και 17 προαιρετικά μαθήματα, με πειράματα και ερωτήσεις κατανόησης.

Η πρόοδος παραμένει τοπική στον φυλλομετρητή. Πρόκειται για έναν κοινό κωδικό τάξης, όχι ατομικούς λογαριασμούς. Όποιος γνωρίζει τον κωδικό μπορεί να διαβάσει και να αντιγράψει τα μαθήματα. Η αλλαγή κωδικού απαιτεί νέα κρυπτογράφηση.
